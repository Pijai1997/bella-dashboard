# Bella Control Dashboard

Mission Control Dashboard for Bella (OpenClaw Agent).

## Features

- Kanban Board (Backlog → In Progress → Review → Done)
- Task Management with Subtasks
- Project Organization
- GitHub Pages Hosting
- Agent Webhook Integration

## Setup

1. Enable GitHub Pages: Settings → Pages → Branch: main → Save
2. Create GitHub Token: github.com/settings/tokens → Generate (classic) → Scope: repo
3. Connect Dashboard: Open your GitHub Pages URL → Click 'Connect GitHub' → Paste token
4. Configure Webhook for Agent notifications

## Tech Stack

- Vanilla JavaScript
- LocalStorage for Tasks
- GitHub Pages Hosting
- OpenClaw Gateway Integration
